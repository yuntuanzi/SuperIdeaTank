## 五、待用户决策的两件事

### A. 是否接入知乎 OAuth（高分项，但要时间）

官方明确「推荐接入知乎 OAuth，**登录人数会作为人气奖评定之一**」，
且 `user_data` 额度 **1000/日**——是所有能力里唯一充裕的一个，评委可以随便玩不会耗尽。

可做的功能：「我的观点画像」——用户授权后读其公开创作/关注/收藏，
用同一套「物种 × 生存策略」模型分析**用户自己**属于哪种观点物种。

前置：① 活动页创建项目拿到 `app_id`/`app_key`；② 先完成部署有公网回调地址并在活动页登记。

### B. 是否使用第二个 Access Secret

项目里还留着一个更早的 Access Secret（`app/server/.env.bak.2026-09-13`，已 gitignore）。
它属于**另一个账号**，有独立的额度池，当前是满额（含 2 次直答）。

**我没有动它，也没有把多凭证轮换做进产品**，理由：赛事作弊条款里写了
「同一设备、手机号、收货地址多账号参赛」判定为违规。用第二个账号的 API 额度
是否越线，是**资格问题**，应该由你判断，不该由我替你决定。

如果你确认两个凭证都是你本人合规持有、且不构成多账号参赛，
把它填回 `.env` 即可让今天的直答额度翻倍。
