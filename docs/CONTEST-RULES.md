## 1. 评分权重（最重要的一页）

### 初审（9/15–9/17 滚动打分，决定能否进 Top 15）

| 维度 | 权重 | 说明 |
|---|---:|---|
| **AI 场景价值** | **40%** | 是否构建了有意义的 AI 场景；是否解决真实用户/业务痛点；能否在知乎生态内产生实际价值（效率、体验、内容质量） |
| 创新度 | 25% | 场景选择是否有想象力，玩法是否新颖 |
| 完成度 | 25% | 产品是否可用、体验是否流畅、**Demo 是否跑得起来** |
| 产品体验与设计感 | 10% | UI/UX 是否美观、交互是否符合直觉 |

初审评委团 = 知乎内部各业务线负责人。

### 决赛路演（9/19，若入围）

| 维度 | 权重 |
|---|---:|
| AI 场景价值 | 35% |
| 创新度 | 25% |
| 完成度 | 25% |
| 产品体验与设计感 | 8% |
| 计划书和演示环节 | 7% |

路演形式：北京 798 线下 / 腾讯会议线上，**每组 3 分钟 Demo + 2 分钟 Q&A（最多 2 个问题）**，以实操演示为主。

### 由权重推出的行动排序

1. **完成度（25%）是唯一会「归零」的维度** —— Demo 打不开，其余分数无意义。→ **部署是 P0**
2. **AI 场景价值（40%）** —— 必须让「AI 在哪一环创造了什么价值」清晰可见、可当场演示
3. **创新度（25%）** —— 概念本身（观点生态缸）已经足够独特，靠产品说明把差异讲透
4. **设计感只有 10%** —— UI 美化值得做，但**不值得为它牺牲部署与可用性**

## 7. 尚未利用的官方能力（潜在高分项）

产品说明会被按「AI 场景价值 40%」打分，而我们目前只用了热榜 / 搜索 / 问题回答 / 直答。
以下两项额度充裕且**官方明确鼓励**，是性价比最高的加分方向：

| 能力 | 日额度 | 可做的事 |
|---|---:|---|
| `user_data` + **OAuth 登录** | **1000** | 「我的观点画像」：用户授权后读其公开创作/关注/收藏，用同一套物种 × 策略模型分析**用户自己**属于哪一种观点物种。官方明确说「推荐接入 OAuth，登录人数计入人气奖」 |
| `knowledge` 知识库 | **500** | 备选：把缸内回答灌入知识库做 RAG 检索式追问 |

**OAuth 路径的前置条件**：① 活动页创建项目拿到 `app_id`/`app_key`；② 已有公网回调地址（即先部署）。
两个条件都需要用户操作，因此这条列为 **P1**，在 P0（部署 + 标注器 + UI + 文档）完成后再评估是否来得及。
