## 4. 设计方向（这是「怎么做」，不是「做什么」）

### 4.1 主题定名：**深海观测舱 / Deep Observation Deck**

外层是**冷静的浅色仪器面板**（浅暖灰 `#F3F3EE` 系，已有），
中心是**一块深蓝观测窗**（`#0D1B2E` 系，已有）。
两者的**对比度落差本身就是视觉主张**——现在的问题是这个落差没有被用足：
深色画布只占了页面一小块，四周被同质的浅色卡片稀释了。

**核心手法：让观测窗变成绝对主角。**
- 观测窗上下留出更大的呼吸区，宽度尽量吃满内容区
- 观测窗四角加**细描边 + 角标刻度线**（像仪器取景框），不是圆角卡片
- 观测窗内的 HUD 芯片改成**贴边悬浮**，不要挤占画面中心

### 4.2 排版层级（当前最大的短板：所有字号都差不多）

建立明确的四级字阶，拉开对比：

| 级别 | 用途 | 建议 |
|---|---|---|
| Display | 首页 hero 主张 | 40–52px / 字重 600 / 行高 1.25 / 字距 -0.5px |
| Title | 问题标题、面板标题 | 20–24px / 字重 500 |
| Body | 正文、摘要 | 14px / 行高 1.7 |
| Meta | 标签、脚注、数据 | 11–12px / 字重 400 / 颜色降到 `--ink-3` |

**数字要用等宽字形**：赞同数、概率、计数一律 `font-variant-numeric: tabular-nums`，
并给数字单独提一档字重（500）。数据产品的可信感一半来自数字排版。

### 4.3 物种节点的视觉编码（**最重要的一项**）

现在每个节点只编码了 2 个维度（面积=能量、颜色=立场），
策略靠圆下方一行小字，10 个节点就是 10 行小字，视觉噪音极大。

**改成四维编码：**

| 维度 | 编码方式 |
|---|---|
| 能量（赞同数） | 圆面积（保持） |
| 立场（6 类） | 填充色 + 描边色（保持，但配色要重做，见 4.4） |
| **生存策略（6 类）** | **圆内部的极简符号**，纯描边线条，14×14 视觉尺寸 |
| **权威等级（1–4）** | **描边粗细**：1 / 1.4 / 2 / 2.8px |

策略符号建议（自己画 SVG path，纯线条，不要 emoji）：

- 数据论证 → 三根递增竖柱
- 情绪共鸣 → 一段波浪线
- 故事叙事 → 一条带起点圆点的折线
- 身份站队 → 一条竖分割线两侧各一点
- 抖机灵 → 一个折角闪电/感叹号变体
- 引用权威 → 一对引号

**文字标签规则**：只有能量 Top 3 的节点常驻显示策略名；
其余节点 hover / 点击才显示。小圆（r < 26）内不放任何文字。
—— 现在小圆里塞「中立」两个字导致文字溢出圆外，必须修掉。

### 4.4 立场配色重做

当前深色画布上的 6 色（`STANCE_DARK`）区分度不足，
「中立/解构/补充」在深底上几乎同色。
**但 `types.ts` 不许改** —— 所以请在 `Tank.tsx` 内部定义局部配色常量覆盖，
或用 CSS 变量。

要求：
- 6 个色相在 `#0D1B2E` 底上**两两可辨**（色相间隔 ≥ 45°，或用明度差补足）
- 保持**低饱和 + 半透明填充 + 亮描边**的既有质感，不要变成糖果色
- 提供**色盲友好**的备用区分：填充透明度分两档（支持/反对/解构 一档，中立/反讽/补充 另一档）
- 图例条同步更新

### 4.5 运动（克制，但必须有）

一个叫「进化缸」的产品完全静止，是概念上的失分。

**允许且推荐**：
1. **时间轴拖动时的节点入场过渡**——节点从 `r=0` 缓动到目标半径（180ms，`cubic-bezier(.22,.61,.36,1)`），位置用 CSS transition 或 requestAnimationFrame 插值。
   现在是每次重算直接跳变，非常突兀。
2. **环境参数切换时的半径过渡**——同上，让「重算」肉眼可见。
3. 节点 hover：描边加粗 + 轻微上浮（`transform: translateY(-1px)`），120ms。

**禁止**：pulse 呼吸动画、glow 扩散、粒子、自动播放的循环动画。
运动只在**用户操作后**发生，且 ≤ 200ms。

### 4.6 首页（HotBoard）

现在是「hero 段落 + 搜索框 + 热榜列表」，结构对，但气质弱。

- hero 的三行主张保留，但**字号拉到 Display 级**，并把副段落收窄到 `max-width: 46em`
- hero 下方加一行**三个能力锚点**（横排，细描边分隔）：
  `观点物种识别` / `演化时间轴重建` / `放生存活预测`
  —— 让评委在滚动前就知道产品有什么
- 热榜列表：序号数字放大到 22px 且用 `tabular-nums`，
  hover 时整行左侧出现 2px 竖线（已有，保留），行高加大到 ≥ 72px
- **给已有缓存的热榜条目加一个「缸已就绪」小徽标**
  —— 这个数据前端拿不到，**先不做**，只在报告里提出来（我会在服务端补 API）

### 4.7 放生报告卡片

- 概率仪表盘保留 3/4 圆弧，但**数字放大到 28px**，并在弧下标注 `存活概率`
- 「AI : 规则 = 6:4 混合」这句话现在是一行灰字，容易被忽略——
  改成**两段式小条形**（AI 一段、规则一段），让"混合"这件事可视化
- 风险 / 杂交建议列表：加左侧 2px 色条区分（风险=暖色，建议=主色）

### 4.8 响应式

- ≥1280px：生态缸与右侧工作台**并排**（当前 `tank-layout` 已有 grid，检查断点）
- 768–1279px：上下堆叠
- <768px：单列，观测窗高度降到 360，HUD 芯片换行
- **页面 body 任何宽度下都不许横向滚动**
