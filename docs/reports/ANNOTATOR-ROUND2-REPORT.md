## 1. 新增特征清单（一行一条 + 针对的语言现象）

### 1.1 首句判词特征族（spec 2.1）——只在开头 ≤30 字或首句标点之前匹配

| 特征 | 权重 | 落点 | 语言现象 |
|---|---|---|---|
| `^(不能/不会/不行/不可以/不太能/不太会/不太行/不至于/没(有)意义/没用/没必要/不可能/难说)` | 3.0 | 反对 | 中文回答面对「能否/该不该」型问题用一两个字判词开篇再展开论证 |
| `^(很难/难以/恐怕不/基本不/未必/难言)` | 2.6 | 反对 | 程度化否定判词开篇（「很难平息争议，因为…」） |
| `^.{0,6}(翻车/塌房/洗白/卖惨/双标/装无辜)` | 2.6 | 反对 | 开篇直接给事件或当事人下负面定性，再补论据 |
| `^(能/会/可以/当然/肯定/值得/确实如此)+紧跟标点` | 2.8 | 支持 | 直接肯定判词开篇（要求紧跟标点，防止「能达到…」这类叙述句首误中） |
| 首句为反问句且含 `难道/凭什么/怎么会/什么样/有什么用/有何意义/何苦/你觉得呢` | 1.5 | 反对（弱） | 以反问句开篇通常隐含对题干或常识立场的否定；只认挑战语气疑问词，纯咨询式问句（「谁发展会更好呢？」）不算 |
| `^(先说结论/结论先行/这个问题问反了/问题本身就有问题)` 或开头含 `抛开…事实不谈` | 1.6 | 解构 | 元评论开篇说明回答要重设问题框架 |
| 开头含 `(没有/无)(什么)争议` | 2.8 | 中立（正向） | 开篇自陈无争议是明确的不站队表态 |

权重量级为普通全文特征的 2–3 倍；在 `applyQuestionPrior` 之后单独计入，
**不被 why/howto 的 0.55 先验衰减**（衰减针对全文密度类特征，判词是位置信号）。

### 1.2 立场·全文新增

| 特征 | 权重 | 落点 | 语言现象 |
|---|---|---|---|
| `(并不/毫不)(无辜/冤枉)` | 1.8 | 反对 | 「并不无辜」是中文常用的部分否定判词 |
| `了说是` | 2.6 | 反讽 | 句尾「了说是」是阴阳怪气式转述腔（「招聘到超人了说是」） |
| `都(没/没有)这么(狠/夸张/离谱/拼/卷)` | 2.2 | 反讽 | 「连……都没这么……」比较级归谬是常见嘲讽句式 |
| `没有标准答案` | 2.6 | 中立（正向） | 显式承认问题无定论（spec 2.3） |
| `分情况/视情况而定/具体情况具体分析/因人而异/因情况而异` | 2.4 | 中立（正向） | 把判断交给条件是典型不站队 |
| `(两边/双方/两派)都有(道理/可取之处/问题)` | 2.4 | 中立（正向） | 双向认可说明拒绝选边 |

| `(没有/并无/不存在)(什么)争议` | 2.2 | 中立（正向） | 直接声明无争议即不站队（初版 `没有.{0,3}争议` 会误中「没有平息争议」，已收紧） |

### 1.3 策略新增/调整

| 特征 | 权重 | 落点 | 语言现象 |
|---|---|---|---|
| **删除** 裸数字 `\d+(\.\d+)?%?`（0.9）与裸量级词 `[万亿倍元]`（0.35） | — | 数据论证 | spec 2.2：单纯出现年份/数量不计分 |
| 数字与论证连接词（因此/占比/相比/增长/下降/锐减/超过/达到/约为/将近/相当于/平均/统计/换算/低于/高于/足足/仅有/只有/翻倍/率）**同句**出现 | 2.4/句（cap 2） | 数据论证 | 数字必须服务于论证行为才算数据论证（spec 2.2 方案 B） |
| 编号列点 `[一二三四…\d]+[、.．]` | 1.2→**1.5** | 数据论证 | 删掉裸数字后，结构化归因的编号列点需要补足区分度 |
| `笑死/笑不活(了)/绷不住了` | 2.4 | 抖机灵 | 口语笑场标记说明语境在玩梗而非严肃论证 |
| `了说是` | 2.2 | 抖机灵 | 阴阳怪气式转述句尾，常见于甩梗回答 |
| ≥3 轮 `XX：` 说话轮次 | 3.0 | 故事叙事 | 多轮对话体是实录转写，属叙事；对话里的数字（营业时间、时长）是引语内容，不构成数据论证 |
| 开头判词 + 全文 ≤80 字 | 2.4 | 抖机灵 | 「判词+一句解释」的超短回答是知乎典型的甩观点机锋体裁 |

### 1.4 机制修正（非词典，但同等重要）

- **立场/策略置信度解耦**：旧逻辑 `confidence = min(stanceConf, strategyConf)` 且
  `confidence < 0.15 → 立场强制中立`。一句话短回答没有任何策略特征时 strategy 落入兜底类、
  置信度为 0，会把明确的立场表态一起抹成中立——这是「立场退化」告警的另一半机制。
  现在：只看 `stanceConf < 0.15` 决定是否退回中立。
- **why/howto 保持保守耦合**：归因/方法类回答里的否定词大多在陈述而非表态，
  这类问题下若策略侧也完全零证据（纯兜底），立场表态仍退回中立
  （保住既有对抗测试 `adversarial priors dampen…` 的语义）。
- **策略零证据不参与 confidence 取小**：strategy 纯兜底（topScore=0）时
  `confidence = stanceConf`，否则真中立和带明确判词的回答都被拖到 0，
  spec 2.3 要求的正向中立置信度形同虚设。

## 4. spec 2.2：选了方案 B（提高区分度），理由

- **可解释性**：B 把「数字是否服务于论证」变成逐条可见的 evidence
  （「数字+连接词同句」的原文片段直接进入 evidence.strategy），
  A 的缸内相对分位在单条证据里无法解释「为什么这条不算数据论证」。
- **架构约束**：`annotateOne` 是单条纯函数，两套验收闸都直接调它；
  A 需要缸级上下文（cohort），闸根本测不到该逻辑，等于给核心逻辑留了一个测试盲区。
- **产品语义**：B 与现有词典风格一致（特征=可复用语言现象）；A 的正确性依赖缸内构成，
  换一个缸同样的回答会得不同标签，对「可解释标注」的产品承诺是倒退。

附带发现：删掉裸数字后 v1 fx13 的「数据论证」被身份站队反超（1./2、编号是唯一证据），
编号列点权重从 1.2 提到 1.5 补回——这不是为过闸调参，而是裸数字删除后
结构化归因信号需要重新配平。

## 7. 发现但未修的问题 & 对人工标注的异议

### 7.1 发现未修

1. **策略维度没有「无显著策略」兜底类**：零证据回答被 `pickWinner` 的 fallback
   默认标成「数据论证」（清朝缸 #1/#4/#5/#7，v2 有 4 条策略命中是兜底撞对）。
   这是策略侧「数据论证泛滥」的残留来源，清朝缸的策略告警有一半是它贡献的。
   修法需要产品决策（加第七类标签，或启用方案 A 的缸内相对化），本轮 spec 二选一未动。
2. **howto 型问题的「立场」定义模糊**：罗永浩缸的回答多为建议/玩梗（「不需要任何公关」
   「这老东西搁这要优惠券呢」），立场词典对建议体没有覆盖。即使去掉全部先验耦合
   也有 8/10 零立场证据——这个缸的 10/10 中立告警**大体属实**（特征稀疏），不是本轮回归。
3. **fx12 残留误例**（期望支持/机器反对）：「我从不反对职场拼搏…但我极其反感无意义加班」，
   否定副词密度压过了真正的认同对象。修它需要「否定之否定/认同对象」级别的句法特征，
   超出本轮范围，未动。
4. **北大缸、酒店缸立场告警保留**：抽查答案多为解释型长文，判词/表态稀疏，
   倾向认为告警属实（真中立居多），建议人工复核而非继续加特征。

### 7.2 我认为人工标注里值得重看的（请你定夺）

- **v1 fx05 策略（你标数据论证，机器引用权威）**：该条同时有「先说法条/按照相关的法律法规」
  和「8月5日/未来3年计划」，是法条+事实混合体，判引用权威并非没有依据，可再斟酌。
- **v2-03 策略（你标数据论证）**：全条没有阿拉伯数字（「十七个小时」是汉字数字），
  说服方式是靠「连麦切片大家都可以去看」的事实援引+情绪否定，六类里没有贴切标签；
  机器这条是兜底撞对的，不是真识别。数据论证可接受但勉强。
- **v2-07 策略（你标抖机灵，机器数据论证）**：「一天睡眠只有7个小时」触发「数字+只有」
  同句，是方案 B 的边缘案例——你的抖机灵更准，这算机器误例，供你评估 B 的边界。
- **v2-09 策略（你标抖机灵，机器数据论证）**：数据论证与抖机灵同分 2.4 平局，
  按词典序落败；两个标签都有依据，不算你判错。
- **v1 fx11 立场（你标中立，机器补充）**：「会算另外一笔账」确实是追加视角，补充也不离谱；
  维持你的中立更稳，列为机器误例。
